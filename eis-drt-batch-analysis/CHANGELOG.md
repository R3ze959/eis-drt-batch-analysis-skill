# 更新记录

## 1.0.0 — 2026-09-11

- 首个 1.x 源码发布版：独立 EIS 与 DRT、数据优先导出、自动诊断图、按需展示图。
- 汇总此前候选版的隐私清理、通用路径启动、锁定环境和可恢复导出；不携带私人案例、环境或真实实验数据。
- 更新首次安装和转发说明，明确 macOS arm64 验收与 Windows/Linux 未实机验收边界。
- 数值算法与 0.2.3.dev2 一致，没有新增参数调优；版本/代码指纹改变，旧结果保留原软件，不跨版本续跑。

## 0.2.2 — 2026-09-11

- 发布前故障模拟：EIS 最终分类报告与根报告同步，并更新所有权哈希；绘图启动异常不丢失数据，重导出失败不再留下上次成功的当前状态。
- 普通 EIS 续跑只重试此前失败/超时的已请求一致性检查，记录历史；export-only 仍不计算，已成功检查不重复。
- 共享入口拒绝覆盖解析器溯源字段、非有限归一化值、清单重复列/错列和与源级解析冲突的逐谱选项。
- DRT 同步输入前后哈希检查与整源准备事务；一条源文件的后续谱准备失败时不泄漏前半部分为已接受结果。全输入失败也发布完整、可追溯的失败报告。
- 拒绝 NaN/Infinity 数值选项；补充真实 PowerShell 示例与分支字体说明。每项可复现故障纳入 prepublication_test.py，未为私人 holdout 重新调参。
- 补齐 pandas 的 Windows 条件依赖 tzdata 2026.3，按平台 marker 核验与记录实际版本；增加三平台依赖元数据闭包测试，不冒充跨平台实机验收。

## 0.2.1 — 2026-09-11

- 共享解析器保留 SI 前缀大小写，区分 MHz/mHz、MΩ/mΩ，支持 n/µ 前缀；保持带前缀 ohm·cm² 基准，拒绝未支持的面积单位/面积分母而不是降为 ohm。
- 统一 Unicode 减号和负虚部别名；辅助模值/相位不再猜测角度单位并改写明确符号，模糊符号需要显式约定。
- EIS→DRT 只交接原用户元数据，避免解析器源行、时间等数组在 CSV 中字符串化后覆盖重解析结果。拒绝用户元数据覆盖解析器追溯字段。
- 独立 input_quality_status；坏行、重复频率和倒序/异常时间不能被 KK 低残差掩盖。倒序时间在共享 parser QC 中标 suspect，不自动删除。
- 核对清点、解析前后源文件哈希；拒绝非有限模值，单源失败仍保留审计并允许批次继续。
- 新增数据含义反例回归；不更改 DRT 求解器、私人参数或留出数据。代码指纹改变，旧输出不可跨版本 resume。

## 0.2.0 — 2026-09-11

- 新增 batch_eis.py：共享解析/身份/元数据基础，独立 EIS-only schema 1，默认不运行 DRT 或物理等效电路拟合。
- 数据优先导出 Z′、−Z″、Z″、|Z| 和带符号相位；源文件哈希、逐行账本、UID、单位和解析失败均可追溯。
- 可选全点 Lin-KK（保留 L/C 项）和 Z-HIT，独立超时；不把一致性通过当作测量有效或 DRT 适用性认证。
- 内置逐谱 Nyquist/Bode PNG+SVG、原始开口点、尺寸/文字检查及尺度相关留白；保留电感点和小阻抗量级细节。
- EIS 数值检查点先于表格/图片保存，严格同模式续跑、可恢复派生重导出、不覆盖未知文件；导出原始数据 DRT 交接清单。
- 同一 Skill、同一锁定环境、EIS/DRT 两个独立输出分支；没有新依赖、不打包真实实验数据。新增合成和真实 CLI 回归。
- DRT 求解器和 0.1.0 方法参数未修改，但升级改变代码指纹，须使用新输出目录。

## 0.1.0 — 2026-09-10

- 困难谱新增同网格、同 R/L/C 非负背景项的正核/signed 核频率 CV；记录候选、λ边界、全点重拟合及敏感性数组。默认主曲线保留，推荐只针对重建。
- Loewner 使用固定频率参考候选进行无量纲条件化，全点重拟合可用性先于阶数简约选择；保留原后端导出身份。
- 非串联电感筛查增加局部残差稳健尺度的噪声门槛；仅为工程筛查，不是噪声置信区间或 RL 物理证明。
- 文本逐行账本覆盖无效行和失败解析，归一化 CSV 显式回连源行；增加主动指定单谱乱序的稳定排序入口，拒绝重复频率/疑似混谱。
- 发布白名单纳入新回归和说明，保持自包含解析、固定依赖、合成示例、可恢复派生导出；不带私人或公共真实实验数据。
- 相比 beta.4 改变执行指纹，不直接续跑旧结果。研究工具版本号不代表全部实验可通过科学验收。
